Noticiero y casos

Publica noticias y casos de éxito en la web de Torama. Entra con tu llave de acceso de GitHub.

¿Cómo consigo mi llave?
  1. Necesitas una cuenta de GitHub con permiso de escritura en el repositorio WebTorama (pídeselo al administrador).
  2. Abre GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. En Repository access elige Only select repositories y marca WebTorama.
  4. En Permissions → Repository permissions pon Contents: Read and write.
  5. Pulsa Generate token, copia la llave y pégala aquí.

La llave se guarda solo en este navegador y se usa únicamente para hablar con GitHub. No la compartas.
