¿Cómo consigo una llave de GitHub?
  1. Necesitas una cuenta de GitHub con permiso de escritura en el repositorio WebTorama.
  2. Abre GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. En Repository access elige Only select repositories y marca WebTorama.
  4. En Repository permissions pon Contents: Read and write y genera la llave.

La llave se guarda solo en este navegador. No la compartas.
